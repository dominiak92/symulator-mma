# Symulator Polskiego Zawodnika MMA · Ground Game

Przeglądarkowa gra tekstowa: kariera polskiego zawodnika MMA od turniejów amatorskich po pas mistrza świata, w identyfikacji Ground Game.

Cała gra to jeden plik `index.html` (React + TypeScript, zbudowany Vite). Działa na GitHub Pages, Netlify i po otwarciu z dysku. Zapisy kariery zostają w przeglądarce gracza.

Wszystkie postacie, nazwiska, kluby, gale, federacje i sponsorzy w grze są fikcyjne. Podobieństwo do prawdziwych osób i firm jest przypadkowe. Prawdziwa jest tylko marka Ground Game.
